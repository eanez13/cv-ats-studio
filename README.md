# CV ATS Studio

Aplicación web gratuita para armar un CV que pase los filtros ATS y adaptarlo a cada vacante.

- Importá tu CV (PDF, Word o foto) y se completan los campos solos.
- Adjuntá el aviso (foto, PDF o texto): calcula el match y la probabilidad de pasar el filtro.
- Adaptá tu CV con vista previa de cada cambio y guardá una postulación por vacante.
- 6 plantillas de una columna, compatibles con ATS. Descarga en PDF, Word y TXT.

Todo funciona en tu navegador: tus datos no se envían a ningún servidor.
